# SignalAI Pro 2.0 RC1.2

- Fixed search input focus loss after every typed character.
- Money values and forecast price ranges are displayed with two decimal places.
- Forecast horizons: 15m, 30m, 60m, 120m, 240m, 1d, 2d, 5d, 10d.
- Long-range forecasts now use broader Binance candle intervals rather than only 1-minute data.
- Version label updated to RC1.2.

Forex, precious metals, indices and commodities require a second market-data provider and are intentionally not represented as Binance symbols. The provider abstraction is planned for the next release.
